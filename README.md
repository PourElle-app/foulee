# Foulée — application Android

Analyse de foulée gratuite : l'IA (MediaPipe Pose, Google, licence Apache 2.0) fonctionne dans le téléphone, aucune vidéo n'est envoyée sur Internet.

- `www/index.html` : l'application ; `www/mp/` : les fichiers de l'IA
- `android/` : l'emballage Android (Capacitor)
- L'onglet **Actions** fabrique l'app (.aab pour le Play Store, .apk pour essayer).
